# PC Periphery Builder — Assignment 4

## Запуск

Нужен JDK 8 или новее. Откройте папку проекта и выполните:

```sh
javac -d out src/pcperipherybuilder/*.java
java -cp out pcperipherybuilder.Main
```

В IntelliJ IDEA откройте проект, выберите JDK и отметьте папку `src` как Sources Root. Запустите `Main.main`. Папка `pcperipherybuilder` должна находиться внутри `src` и соответствовать объявлению package.

## Шесть классов

| Класс | Ответственность |
|---|---|
| DeviceRegistry | Хранит модели, типы, соединения, состояния подключения и настройки; проверяет данные и дубликаты |
| CompatibilityService | Проверяет количество USB-портов и поддержку Bluetooth для всей конфигурации |
| ConnectionManager | Подключает устройства, отслеживает новые подключения и откатывает их при сбое |
| ProfileService | Проверяет состав и подключение устройств, затем применяет DPI и surround sound |
| PCPeripheryFacade | Координирует четыре подсистемы через простой API |
| Main | Использует только Facade |

Данные устройств хранятся в стандартных Map и Set внутри DeviceRegistry, чтобы не вводить отдельные классы моделей. Для небольшого учебного проекта это позволяет сохранить ровно 6 классов; при расширении проекта отдельная модель устройства была бы удобнее.

## Порядок работы

Facade получает данные из реестра через сервисы: проверка совместимости -> подключение -> применение профиля. Gaming устанавливает DPI 16000 и surround true; Office — DPI 1200 и surround false. Клавиатура остаётся подключённой с теми же физическими характеристиками.

Проверка профиля завершается до изменения настроек. При сбое подключения ConnectionManager отключает только устройства, подключённые в текущей попытке, в обратном порядке. Уже существовавшие подключения сохраняются. Если проверка профиля завершилась ошибкой, Facade запрашивает такой же откат. Повторный запуск не переподключает устройства, повторное выключение допустимо.

Подсистемы не содержат ссылок на Facade. Их публичные методы доступны продвинутому клиенту напрямую; основной Main использует только Facade.

## Демонстрация ошибок

В Main можно временно заменить создание Facade:

```java
// Недостаточно USB-портов: нужны два.
PCPeripheryFacade facade = new PCPeripheryFacade(1, true);

// Нет поддержки Bluetooth для клавиатуры.
PCPeripheryFacade facade = new PCPeripheryFacade(2, false);

// Имитация недоступной гарнитуры: ранее подключённые мышь и клавиатура отключатся.
PCPeripheryFacade facade = new PCPeripheryFacade(
    2, true, java.util.Collections.singleton("SoundMax H7")
);
```



## Пять принципов Clean Code

1. Понятные имена: startGamingSetup, validate, connectAll и shutdown выражают назначение.
2. Единственная ответственность: реестр хранит данные, проверка совместимости проверяет возможности ПК, менеджер управляет подключениями, сервис профилей меняет настройки. Facade координирует.
3. Инкапсуляция: клиенту не передаются внутренние Map, устройства или экземпляры подсистем.
4. Небольшие методы и отсутствие повторения: два профиля используют общий процесс запуска, параметры применяются общей процедурой.
5. Проверка данных и обработка ошибок: неверные значения отклоняются, совместимость проверяется до подключения, частично выполненное подключение откатывается.
